生日寻宝 H5 · V1.0 手机网页原型

【如何预览】
1. 解压 ZIP。
2. 将整个 birthday_h5_v1 文件夹上传到静态网站托管服务，或用本地静态服务器打开。
3. 入口文件是 index.html。
4. 不建议直接双击 index.html 作为最终测试方式；部分浏览器对本地文件的资源加载和 localStorage 有限制。

【当前包含】
- 六个场景：首页、神秘来信、回忆博物馆、友情暗号、星愿收集、最终宝藏。
- 互动：拆信、收集三枚记忆碎片、选择谜题答案、点亮三颗星星、打开礼物。
- 本地进度保存：刷新页面后会保留当前进度。
- 手机竖屏布局；不依赖后端或第三方 JavaScript 框架。
- 10 张角色动作图、6 张页面背景、32 张互动道具和 UI 透明 PNG。

【最重要：先改这里】
打开 js/content.js，修改文字即可个性化：
1. memories：三段你们的真实回忆及卡片标题。
2. question：友情暗号题目。
3. options：A/B/C 三个选项。
4. correctAnswer：正确答案，填写 A、B 或 C。
5. wishes：三条生日祝福。
6. birthdayTitle、birthdayParagraphs、signature：最终生日信标题、正文和署名。

【照片替换】
可以把真实照片放入 assets/photos/，然后修改 index.html 中回忆页的卡片内容和图片路径。当前回忆卡片先使用通用贴纸占位。

【重要】
- 当前是可交互原型，示例文案需要替换成你们真实的回忆和暗号后再发送。
- 语音、视频和真实礼物链接尚未接入，可在最终页继续添加。
- 如需在微信中分享，请部署到 HTTPS 静态网站，并用手机微信实际测试。
- 点击最终页“从头再玩一次”会清除本网页保存的闯关进度。
